## Early Days: 1990s Web Pioneer

I started building for the web in the 1990s, when the internet was still a conversation between curious minds rather than a surveillance economy. As GitHub user #439, I witnessed and participated in the transformation of how humans connect through technology.

Those early days shaped my core belief: **technology should amplify human conversations, not replace them.**
