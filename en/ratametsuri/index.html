Ratametsuri is an app for planning orienteering courses on the Mac.

What you need

  • A Mac with macOS 14 Sonoma or later
  • A map as a PDF or an image file

What Ratametsuri can already do

  1. 1Controls go where you meant them

    While you add controls, the text next to the pointer tells you what a click will do, such as “Add 31 as 4” or “Insert between 2 and 3”. Click a control that's already on the course and it's only selected, never added twice by accident.

  2. 2Control descriptions lay themselves out on the map

    On a course with many controls, the descriptions run on into a second column. Every course gets its own PDF with the descriptions on the map.

  3. 3Courses go into MeOS as they are

    You export the courses as an IOF XML file and MeOS reads them straight in. Nothing changes for whoever runs the results.
