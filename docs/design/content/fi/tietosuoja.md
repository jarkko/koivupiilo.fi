# Tietosuoja

Koivupiilo.fi ei käytä evästeitä eikä seuraa kävijöitä sivustolta toiselle.

## Kävijämäärät

Sivusto laskee, kuinka monta kertaa sivuja on avattu ja mistä linkeistä niille on tultu. Laskuri ei tallenna IP-osoitteita eikä tunnista yksittäisiä kävijöitä. [vahvista: laskurityökalu valitaan rakennusvaiheessa]

## Palvelin

Sivusto on GitHub Pagesissa. GitHub voi tallentaa kävijöiden IP-osoitteita palvelunsa turvallisuuden takia. Fontit ladataan tältä sivustolta, ei kolmansien osapuolten palvelimilta.

## Sähköposti

Kun kirjoitat Koivupiilolle, osoitettasi ja viestiäsi käytetään vain viestiin vastaamiseen. Viestejä ei luovuteta eteenpäin. Sähköposti kulkee Fastmailin palvelimien kautta.

Voit pyytää nähtäväksi tai poistettavaksi sinusta tallennetut tiedot kirjoittamalla osoitteeseen [vahvista: sähköpostiosoite].
